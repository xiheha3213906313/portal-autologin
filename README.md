# 门户自动登录

用于字节跳动访客 Wi-Fi 门户的 Android 应用，支持普通登录和 LSPosed 自动登录，采用 Miuix 界面。

[下载安装包](https://github.com/xiheha3213906313/portal-autologin/releases/latest) · [更新记录](https://github.com/xiheha3213906313/portal-autologin/releases) · [反馈问题](https://github.com/xiheha3213906313/portal-autologin/issues)

## 普通模式

Android 9 及以上，无需 Root。

1. 连接目标访客 Wi-Fi，打开应用。
2. 填写或选择账号密码，保存后自动尝试登录。
3. 已保存配置时，打开应用或从后台返回即可触发检查；显示“已联网”后，会通过当前 Wi-Fi 在后台复查互联网连接。

遇到未认证却显示联网，可开启“强制登录”，启动应用或保存配置时始终尝试认证。复查失败时也可点击“强制登录”；成功后可在结果页开启该选项。检查只在需要时执行，不持续轮询。

## LSPosed 模式

面向小米系系统，包含小米、Redmi、POCO，需要 Root 和 LSPosed。

1. 启用模块，勾选“小米浏览器 / com.android.browser”作用域。
2. 打开应用，保存账号配置并开启“自动登录”。门户页面打开后会快速填写并提交。
3. 使用“静默登录”时，再勾选“系统框架 / android”作用域并重启手机，即可在后台尝试认证。

非小米设备的模块选项会灰显，仍可使用普通模式。模块安装或更新后需重启手机。

## 功能与说明

- 两种模式共用账号配置，支持账号历史、只读预设和配置切换。
- 静默登录保留前台填写兜底；失败时可手动登录或导出诊断日志。
- 启动时自动检查更新，发现新版本后在标题右侧提示；“关于”页面提供应用内更新和账号分享入口。
- 账号保存在本地；主动分享会打开公开 GitHub Issue 草稿，由用户自行确认发布。

当前适配目标访客门户，已在小米 14 / Android 16 验证模块认证；其他设备仍需实测。
